One-line roast of a fridge whose ice maker has not worked since 2019 — an entry for the make.fun "Roast Your Fridge" bounty (one line, one laugh).

## Entry

The roast itself lives in `line.txt`. Run `main.py` to write those exact bytes to the output file:

```sh
python3 main.py
```

By default the output goes to `/output/entry.txt`; set `MAKEFUN_OUTPUT` to choose a different output path.
